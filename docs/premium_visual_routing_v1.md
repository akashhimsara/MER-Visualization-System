# Premium Visual Routing v1

Song Visual DNA automatically selects only these production visual worlds:

- Liquid Chrome Galaxy
- Neon Mandala
- Cosmic Bloom
- Particle Aurora
- Void Portal
- Neon Lotus
- Solar Eclipse
- Crystal Cathedral

The four early prototype worlds remain available in the controller for manual comparison, but are deliberately excluded from automatic Song DNA selection: Equalizer Ring, Neon Tunnel, Holographic Core, and Horizon Grid.

This keeps the user-facing uploaded-song experience consistently premium while preserving the prototypes for development and demonstration.
