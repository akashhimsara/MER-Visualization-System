Note:
The CUDA version reported by NVIDIA-SMI represents driver-supported CUDA
compatibility and does not by itself confirm the CUDA runtime used by
PyTorch.

The actual PyTorch version, CUDA runtime, and GPU availability will be
recorded after the machine-learning environment is installed.

## Benchmarking Rule

All final latency, CPU, memory and computational-performance comparisons
will be performed on this documented reference machine unless explicitly
stated otherwise.

Any experiment executed on different hardware must record that hardware
separately.
